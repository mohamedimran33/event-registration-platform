# event-registration-platform
Java Spring Boot backend for event management, registration, ticketing and notifications.


A backend application built using Java and Spring Boot
to manage events, attendee registrations, tickets,
waitlists and notifications.

## Goals

- Build REST APIs for event management.
- Implement user authentication and authorization.
- Manage event capacity and waitlists.
- Generate and validate event tickets.
- Learn database transactions and concurrency.

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Redis
- Maven

## Project Status

Currently in development.
